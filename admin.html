Administración Terra PSCJ

Acceso con tu cuenta de GitHub. Los cambios se guardan directamente en el repositorio y se publican solos.

¿Cómo creo el token?
  1. GitHub → tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: “Only select repositories” y elige este repositorio.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Genera, copia el token y pégalo aquí. Es tu contraseña de administrador: no lo compartas.
